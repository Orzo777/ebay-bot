## Частина 1. Окрема пошта

**Навіщо:** особиста пошта окремо від сотень листів KA/eBay; нова адреса одразу підходить для бізнесу
(eBay-бізнес-акаунт, Finanzamt). Боти, картки, команди й таблиця обліку лишаються ті самі.

**Що знадобиться:** телефон (Google надішле код), цей ПК, браузер. До блоку 3 **не міняй email у KA та eBay** —
усе працює як зараз.

### Блок 1 — підготовка (~25 хв, нічого не ламає)

**1.1 👤 Новий Gmail.**
1. Відкрий в анонімному вікні `accounts.google.com/signup`.
2. Ім'я — нейтральне, яке не соромно показати покупцю й податковій (наприклад, назва майбутнього бізнесу).
3. Адреса — коротка, без цифр-року (наприклад `ivan.technik.handel@gmail.com`).
4. Підтверди телефон.

**1.2 👤 Двоетапна перевірка** (без неї не буде пароля застосунку).
1. `myaccount.google.com` → **Безпека** → **Двоетапна перевірка** → **Увімкнути**.
2. Спосіб — SMS або підказка на телефоні.

**1.3 👤 Пароль застосунку → одразу в GitHub** (так боти читатимуть нову пошту).
1. `myaccount.google.com/apppasswords` → назва `ebay-bot` → **Створити**.
2. З'являться 16 букв — **показуються один раз**, не закривай вікно.
3. В іншій вкладці: `github.com/Orzo777/ebay-bot` → **Settings** (вгорі, в репозиторії) → ліворуч
   **Secrets and variables → Actions** → **New repository secret**:
   - Name: `NEW_GMAIL_USER`, Secret: нова адреса → **Add secret**;
   - ще раз **New repository secret**: `NEW_GMAIL_APP_PASSWORD`, Secret: ті 16 букв **без пробілів** → **Add secret**.

**1.4 👤 Дозволити Apps Script API** для нового акаунта.
1. Увійди в браузері новим акаунтом.
2. `script.google.com/home/usersettings` → **Google Apps Script API** → **On**.

**1.5 👤 Вхід для автооновлення коду** (щоб мої зміни самі заливались у новий проєкт).
1. Відкрий PowerShell і вставляй по одному рядку:
   ```
   cd D:\ebay-bot\.clasp-login
   D:\node\node.exe .\node_modules\@google\clasp\build\src\index.js login --use-project-scopes --user new
   ```
2. Відкриється браузер → вибери **новий** акаунт → **Allow**. У PowerShell з'явиться «Logged in».
3. Скопіюй файл входу в буфер:
   ```
   Get-Content $HOME\.clasprc.json -Raw | Set-Clipboard
   ```
4. GitHub → Secrets → **New repository secret**: Name `NEW_CLASPRC_JSON`, Secret — **Ctrl+V** → **Add secret**.

**1.6 👤 Доступ до таблиці обліку.** Відкрий таблицю «Облік перепродажу» (старим акаунтом) → **Поділитися** →
нова адреса → роль **Редактор** → **Надіслати**. Таблиця лишається та сама, нічого не копіюємо.

➡️ Напиши **«готово 1»**.
🤖 Створюю новий проєкт Apps Script у новому акаунті, заливаю код, роблю вебзастосунок і надсилаю тобі два посилання:
на **старий** і на **новий** проєкт. Новий поки нічого не робить (без тригерів).

### Блок 2 — день переходу (увечері, ~25 хв)

Робиться за один раз, по порядку. Найкраще ввечері, коли не чекаєш важливих листів.

**2.1 👤 Kleinanzeigen:** `kleinanzeigen.de` → **Mein Konto** → **Einstellungen** → **E-Mail-Adresse ändern** →
нова адреса → підтверди лист у новому Gmail. Підписки, історія, рейтинг лишаються.
Застосунок KA **не встановлювати** (з ним листи підписок зникали, вересень 2026).

**2.2 👤 eBay:** **Mein eBay** → **Konto** → **Persönliche Angaben** → **E-Mail-Adresse** → нова → підтверди.

**2.3 👤 Старий проєкт** (посилання з блоку 1):
1. Угорі у списку функцій вибери **`transferExport`** → **▶ Виконати**. Унизу — «Записав N властивостей».
   (Усі ключі ботів, eBay, фото товарів і стани переносяться самі — вручну нічого не переписуєш.)
2. Вибери **`uninstallAll`** → **▶ Виконати** — старий проєкт перестає працювати сам.

**2.4 👤 Новий проєкт:**
1. ⚙ **Налаштування проєкту** → **Властивості скрипту** → **Додати властивість**:
   `LEDGER_ID` = частина адреси таблиці обліку між `/d/` і `/edit` (це не секрет).
2. Функція **`transferImport`** → **▶ Виконати**. Перший запуск попросить дозволи:
   **Переглянути дозволи** → новий акаунт → **Додатково** → **Перейти до … (небезпечно)** — це твій власний
   скрипт, а не сторонній → **Дозволити**. Унизу — «Перенесено N властивостей». Тимчасовий аркуш із ключами
   видаляється сам.
3. Функція **`setupAll`** → **▶ Виконати** (знову дозволи, якщо попросить).

➡️ Напиши **«готово 2»**.
🤖 Сам:
- перемикаю GitHub на нові секрети (`NEW_*`) — тобі в GitHub більше нічого не міняти;
- переводжу ботів (вебхуки) на новий проєкт — можливо, попрошу натиснути ще одну функцію;
- автооновлення коду — тепер у новий проєкт;
- перевіряю: картка KA з нової пошти, запис обліку, відповідь бота; пишу в бот, що перехід завершено.

### Що зміниться / не зміниться

- Боти, картки, облік, команди, кнопки — так само. Таблиця обліку та сама.
- Одноразово можуть повторитись нагадування «На сьогодні».
- Старі листи KA/eBay лишаються в старій пошті (мітка «Бізнес KA-eBay»), нові — лише в новій.
- **Відкат**, якщо щось не так: повернути email у KA/eBay на старий і запустити в старому проєкті `setupAll`.

## Частина 2. Закритий GitHub (грудень–січень)

**Чому не просто «зробити приватним»:** бот витрачає ~30 000 хвилин GitHub Actions на місяць (здебільшого
eBay-сторож). Публічний репозиторій — безкоштовно без ліміту; приватний — 2 000–3 000 хв безкоштовно, решта
~$200+/міс. Вихід — **свій маленький сервер** (VPS): на ньому хвилини для приватного репозиторію безкоштовні.

**Що зараз видно у відкритому репозиторії:** код і логіка. **Не видно:** ключів (вони в Secrets), твоїх даних
з обліку (передаються зашифровано), сум у логах, адреси й пошти.

### Крок 1 — 👤 акаунт Hetzner (~10 хв)
1. `hetzner.com/cloud` → **Registrieren** (на нову пошту з частини 1).
2. Підтверди email; Hetzner може попросити підтвердження особи (паспорт або картка) — це нормально.
3. Додай спосіб оплати.

### Крок 2 — 👤 ключ для входу на сервер (~3 хв)
У PowerShell:
```
ssh-keygen -t ed25519 -f "$HOME\.ssh\ebaybot"
```
Двічі **Enter** (без пароля). Потім скопіюй **публічну** частину ключа:
```
Get-Content "$HOME\.ssh\ebaybot.pub" | Set-Clipboard
```
(Файл без `.pub` — секретний, нікому не надсилай і не вставляй нікуди.)

### Крок 3 — 👤 сервер (~5 хв)
Hetzner Console → **New project** «ebay-bot» → **Add Server**:
- **Location:** Nürnberg або Falkenstein;
- **Image:** Ubuntu 24.04;
- **Type:** Shared vCPU → **CX22** (2 vCPU, 4 GB) — найдешевший, якого вистачає;
- **SSH keys:** **Add SSH key** → Ctrl+V → назва `ebaybot`;
- **Name:** `ebay-bot-runner` → **Create & Buy now**.

Скопіюй **IPv4-адресу** сервера.

➡️ Напиши **«готово VPS» + IP** (IP — не секрет).

### Крок 4 — 🤖 налаштування сервера (сам, з цього ПК)
- оновлення, брандмауер, окремий користувач без прав root;
- виконавець GitHub Actions (self-hosted runner) як служба — сам стартує після перезавантаження;
- workflow переводжу на сервер, перевіряю кожен (eBay-сторож, KA, продаж, звіти).

### Крок 5 — 👤 закрити репозиторій (~1 хв)
GitHub → репозиторій → **Settings** → **General** → унизу **Danger Zone** → **Change visibility** →
**Make private** → підтвердь назвою репозиторію.

### Крок 6 — 🤖 перевірка
- сторож версій (зараз читає код із відкритого GitHub) — перевожу на доступ із ключем;
- усі боти й workflow працюють; хвилини GitHub — 0; повідомлю в бот.

Сервер ~4–6 €/міс — як бізнес-витрата (Betriebsausgabe) після реєстрації Gewerbe.
