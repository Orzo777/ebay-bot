# Оперативна пам'ять — шпаргалка

Що ми купуємо і продаємо, як читати наклейку, як не купити не те. Ціни — з бази бота (реальні продажі eBay.de,
щоденний сторож цін).

Останнє оновлення: 04.10.2026.

## 1. Що купуємо і почім продається

«Швидко» — ціна, за яку продається за кілька днів (25% найдешевших продажів), «медіана» — звичайна ціна продажу.

| Тип | Швидко / медіана, € | Як продається |
|---|---|---|
| DDR4 для ПК, 2×16 ГБ | 134 / 154 | швидко — наш основний товар |
| DDR4 для ПК, 2×32 ГБ | 266 / 305 | повільно, дорогий |
| DDR4 для ноутбука, 2×16 ГБ | 108 / 128 | помірно |
| DDR4 для ноутбука, 1×32 ГБ | 117 / 143 | помірно |
| DDR4 для ноутбука, 2×32 ГБ | 236 / 286 | повільно |
| DDR5 для ПК, 2×16 ГБ | 340 / 392 | помірно |
| DDR5 для ПК, 2×8 / 2×24 / 2×32 ГБ | 160 / 395 / 544 (швидко) | повільно |
| DDR5 для ноутбука, 2×16 ГБ | 255 / 282 | повільно |
| DDR5 для ноутбука, 1×16 / 1×32 ГБ | 120 / 231 (швидко) | помірно |
| ECC без буфера (ECC UDIMM), DDR4 2×16 | ~115 / ~130 | звичайна −15%, покупці — сервери/NAS |

Не купуємо: серверну Registered (RDIMM/LRDIMM), DDR3 і старше, одиночні 4/8 ГБ, набори 4×4 / 4×8, «змішані» пари
різних брендів, LPDDR (впаяна в ноутбук), CAMM.

**Швидкість (2400 / 3200 / 6000 МГц) на ціну перепродажу майже не впливає** — головне тип і об'єм. Повільніша пам'ять
працює в будь-якій платі свого типу.

## 2. Чотири види планок — як відрізнити за 10 секунд

| Вид | Для чого | Як виглядає | Код на наклейці | Купуємо? |
|---|---|---|---|---|
| **DIMM (UDIMM)** — звичайна для ПК | настільні ПК | довга, ~13,3 см | PC4-…**U**…, PC5-…**U**… | так |
| **SO-DIMM** — для ноутбука | ноутбуки, міні-ПК, iMac | коротка, ~7 см | PC4-…**S**… | так |
| **RDIMM / LRDIMM** — серверна | сервери | довга, **маленький чип регістра посередині** між чипами пам'яті, часто «x4» | PC4-…**R**… / **L**… | **ні** — у ПК не запуститься, коштує копійки |
| **ECC UDIMM** — ECC без буфера | домашні сервери, NAS, робочі станції; працює і в більшості ПК | довга, **9 чипів на бік** (8 + 1 для ECC), регістра немає | PC4-…**E**… | так, але дешевше на 15% |

**DDR4 чи DDR5:** виріз (ключ) на контактах у різних місцях — одна в слот іншої не встане. На DDR5 є маленький чип
живлення (PMIC) на самій планці. На наклейці: **PC4** = DDR4, **PC5** = DDR5 (PC3 = DDR3 — не купуємо).

## 3. Як читати наклейку

### Заводська (OEM) наклейка — Samsung, SK Hynix, Micron, Kingston

```
16GB 2Rx8 PC4-2666V-UA2-11      ← об'єм ОДНІЄЇ планки · ранги · тип і код
HMA82GU6CJR8N-VK                 ← номер моделі (див. розділ 4)

16GB   — об'єм цієї планки (не всього набору!)
2Rx8   — 2 ранги, чипи x8: звичайна. «x4» (2Rx4, 1Rx4) буває лише на серверній
PC4    — DDR4 (PC5 — DDR5)
2666   — швидкість, МГц
V      — клас таймінгів (нам не важливо)
-U     — ТИП: U = для ПК, S = для ноутбука, R = серверна, E = ECC без буфера, L = серверна LRDIMM
A2-11  — ревізія плати (не важливо)
```

Приклади з наших угод:

- `16GB 2Rx8 PC4-2666V-RE1-11` — **R** = серверна. 03.10 продавець писав «für PC» — це помилка, у ПК не запуститься.
- `16GB 2Rx8 PC4-2666V-EE1-11` — **E** = ECC без буфера (наша покупка 04.10). Продавець писав «Non-ECC» — теж помилка.
- `8GB 1Rx8 PC4-2400T-SA2-11` — **S** = ноутбучна.
- **«2Rx8» — це не «2 × 8 ГБ»!** Об'єм планки — число перед ним (16GB).

### Роздрібна наклейка — Corsair, G.Skill, Kingston Fury, Crucial

```
CMK32GX4M2E3200C16        ← номер набору
DDR4 32GB (2x16GB) 3200MHz 16-18-18-36 1.35V  ver 5.39

32GB (2x16GB) — об'єм УСЬОГО набору і розкладка — друкується на КОЖНІЙ планці набору
ver 5.39      — ревізія (у пари має збігатися)
```

Пастка 29.09: на кожній планці «8GB (2x4GB)» — це **4 ГБ** на планку, а не 8. Продавець назвав чотири такі планки
«32 GB» — насправді 16 ГБ.

Розшифровка роздрібних номерів:

- **Corsair** `CMK32GX4M2E3200C16`: 32G — весь набір, **X4** = DDR4 (X5 = DDR5), **M2** = 2 планки, 3200 МГц, CL16.

  32G — весь набір, **RS** = Ripjaws SO-DIMM (для ноутбука).
- **OWC** `OWC2400DDR4S16G`: 2400 МГц, DDR4, **S** = SO-DIMM, 16 ГБ — пам'ять для Mac (iMac 2017–2019).

Якщо номер незнайомий — гугли його разом зі словом «datasheet» або «spec»: за 10 секунд видно тип.

## 5. Набір чи одна планка

- **«32 GB» без розкладки** — найчастіше 2×16, але буває 1×32 (рідше, для ноутбуків) або 4×8 (дешевше). Дивись фото
  і наклейку; бот попереджає «скільки планок — не вказано».
- **«Preis pro Stück»** — ціна за одну планку. Пара коштуватиме вдвічі більше (03.10: SK Hynix «49 €» за штуку).
- **Заводський набір:** однаковий номер моделі, однакова «ver», серійні номери часто йдуть підряд. Дві різні планки
  («Kingston + Crucial») продаються дешевше — бот їх не бере.
- **Для ПК вигідні пари** (двоканальний режим): 2×16 продається краще за 1×32.

## 6. Підробки і пастки

Справжні підробки пам'яті трапляються рідко (здебільшого китайські «Samsung» з AliExpress). Частіше — **не той товар**:

- **Серверна під виглядом «für PC»** — код R на наклейці, номер з R7 / M393 / PDZ, чип регістра посередині планки.
- **Ноутбучна під виглядом настільної** чи навпаки — дивись довжину і літеру S.
- **Менший об'єм** — «8GB (2x4GB)» на кожній планці; «2Rx8» прочитане як 2×8.
- **Чуже фото** — фото з інтернету без наклейки, на фото інша пам'ять, ніж в описі (у одному оголошенні три різні набори).
  Проси фото наклейок обох планок.
- **Наклейка зірвана або переклеєна** — номер не перевірити; не купуй дорого.
- **Ціна нижче третини ринку** — або помилка (одна планка, інший тип), або шахрай. Бот пише «ПІДОЗРІЛО ДЕШЕВО».
- **Шахраї на KA:** «лише переказ / PayPal Freunde», «я за кордоном, лише пересилка», свіжий акаунт. Платимо тільки
  через «Sicher bezahlen» (Direkt kaufen) або готівкою при самовивозі.

## 7. Перевірка при отриманні (до відгуку й до продажу)

1. **Огляд:** наклейки збігаються з оголошенням, контакти чисті, без подряпин і сколів.
2. **Вставити в ПК / ноутбук** — система бачить повний об'єм (Диспетчер завдань → Продуктивність → Пам'ять: об'єм,
   швидкість, «використано гнізд»).
3. **CPU-Z → вкладка SPD** — виробник, номер моделі, об'єм кожної планки (зчитується з самої планки, не з наклейки).
4. **MemTest86** з флешки — щонайменше 4 проходи без жодної помилки (або TestMem5 у Windows, ~30 хв).
5. Для ігрової пам'яті — у BIOS увімкнути **XMP / EXPO**: має стартувати на заявленій швидкості.
6. Щось не так — одразу спір через eBay / «Sicher bezahlen», поки гроші не пішли продавцю.

## 8. Як продавати

- **Назва:** бренд, серія, об'єм і розкладка, тип, швидкість, номер моделі. Бот готує її в «продати N».
  Приклад: `Corsair Vengeance LPX 32GB (2x16GB) DDR4-3200 CL16 CMK32GX4M2B3200C16`.
- **ECC без буфера** — обов'язково «ECC Unbuffered» у назві (і номер HPE / Dell / Lenovo, якщо є друга наклейка).
- **Фото:** обидві планки з наклейками крупно, плюс скріншот CPU-Z / MemTest86 — покупці довіряють більше.
- **Сфотографуй серійні номери перед відправкою** — захист від підміни при поверненні.
- **Пакування:** антистатичний пакет, картон, DHL Paket із відстеженням.
