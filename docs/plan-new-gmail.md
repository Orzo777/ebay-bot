# План: окрема пошта для проєкту (варіант Б)

Мета: KA, eBay, облік і боти живуть в окремому Gmail-акаунті; особиста пошта — окремо.
Кроки користувача можна робити поступово: до «дня переходу» нічого не ламається, усе працює як зараз.
Після кожного блоку — написати Claude «готово N», далі Claude продовжує сам.

## Блок 1 — підготовка (будь-коли, ~20 хв, нічого не ламає)

1. Створити новий Gmail і увімкнути двоетапну перевірку (myaccount.google.com → Безпека). Без неї не буде пароля застосунку.
2. Пароль застосунку для GitHub (так боти читають пошту): myaccount.google.com/apppasswords → назва `ebay-bot` →
   скопіювати 16 символів. GitHub → Settings → Secrets → Actions → New secret:
   - `NEW_GMAIL_USER` = нова адреса;
   - `NEW_GMAIL_APP_PASSWORD` = ці 16 символів.
3. Увійти в новий акаунт у браузері → script.google.com/home/usersettings → «Google Apps Script API» → On.
4. Вхід clasp для нового акаунта (старий лишається, працює далі). У PowerShell у папці `D:\ebay-bot\.clasp-login`:
   `D:\node\node.exe .\node_modules\@google\clasp\build\src\index.js login --use-project-scopes --user new`
   → у браузері вибрати НОВИЙ акаунт → Allow. Потім `Get-Content $HOME\.clasprc.json -Raw | Set-Clipboard` і
   секрет `NEW_CLASPRC_JSON` (вставити Ctrl+V).
5. Таблиця обліку: «Поділитися» → нова адреса → «Редактор» (таблиця лишається та сама, нічого не копіюємо).

→ «готово 1». Claude створює новий проєкт Apps Script у новому акаунті, заливає код, створює вебзастосунок,
додає функцію `setupAll` (усі тригери одним запуском) і дає посилання на проєкт.

## Блок 2 — новий проєкт (~10 хв)

6. Відкрити посилання → ⚙ «Налаштування проєкту» → «Властивості скрипту» → перенести значення зі старого проєкту
   (Claude дасть список назв; значення — копіювати зі старого проєкту, там само).
7. Угорі вибрати функцію `setupAll` → «Виконати» → дозволити доступ (Gmail, Таблиці, зовнішні запити).

→ «готово 2». Claude перевіряє новий проєкт (читає нову пошту, пише в таблицю, відповідає бот), готує перемикання.

## Блок 3 — день переходу (увечері, ~15 хв)

8. Kleinanzeigen: «Mein Konto» → «Einstellungen» → E-Mail-Adresse ändern → нова адреса → підтвердити з нового Gmail.
   Підписки, історія, рейтинг лишаються. Застосунок KA НЕ встановлювати (з ним листи підписок зникали, вересень 2026).
9. eBay: «Mein eBay» → «Konto» → «Persönliche Angaben» → E-Mail-Adresse → нова → підтвердити.

→ «готово 3». Claude сам:
- перемикає workflow на секрети `NEW_*` (тобі нічого не міняти в GitHub);
- переводить вебхуки ботів на новий вебзастосунок;
- вимикає старий проєкт (код-заглушка через автооновлення — тригери нічого не роблять);
- перевіряє першу картку KA і запис обліку з нової пошти; пише в бот, що перехід завершено.

## Що зміниться / не зміниться

- Боти, картки, облік, команди — так само; таблиця обліку та сама.
- Одноразово: нагадування «На сьогодні» можуть повторитись (стан нагадувань зберігався в старому проєкті).
- Стара пошта: старі листи KA/eBay лишаються там (у мітці «Бізнес KA-eBay»), нові — лише в новій.
- Відкат: повернути email у KA/eBay на старий — старий проєкт можна знову ввімкнути.
