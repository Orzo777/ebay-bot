# Де тримати бота 24/7 — варіанти без картки

Бот бачить ринок лише поки ввімкнений. Ноут «тільки ввечері» → пропускаєш
угоди, що зʼявились і зникли вдень, і статистика набирається у 2–3 рази довше.
Нижче — способи тримати його увімкненим постійно, **жоден не просить картку**.

---

## Порівняння

| Варіант | Картка | Вартість | Точність розкладу | Складність |
|---|---|---|---|---|
| **Старий Android + Termux** | ні | €0 (якщо телефон є) | ідеальна (кожні 30 хв рівно) | низька, 15 хв |
| **GitHub Actions** | ні | €0 (public repo) | «плюс-мінус» (+5–20 хв, зрідка пропуск) | середня, треба акаунт+репо |
| **Raspberry Pi / старий ПК** | ні | €50–70 одноразово | ідеальна | середня |
| Oracle / GCP / AWS free | **так** | €0 | ідеальна | — |

**Рекомендація:** якщо є будь-який старий смартфон — Termux. Інакше — GitHub
Actions (файли вже готові, див. нижче).

## Варіант 1. Старий Android-телефон + Termux (найпростіше)

Телефон на зарядці, Wi-Fi — і все. ~1–2 Вт.

1. Встанови **Termux** з F-Droid (не з Play Store — там стара версія):
   https://f-droid.org/packages/com.termux/
2. У Termux:
   ```bash
   pkg update && pkg install python git rsync openssh -y
   termux-setup-storage           # дозволити доступ до памʼяті
   ```
3. Перенеси папку `D:\ebay-bot` на телефон (через USB у `Download/ebay-bot`,
   або `git clone` якщо заллєш у приватний репо). Тоді:
   ```bash
   cp -r ~/storage/downloads/ebay-bot ~/ebay-bot
   cd ~/ebay-bot
   pip install -r requirements.txt
   ```
4. Створи `.env` (той самий вміст, що на ноуті — ключі eBay/Telegram).
5. Запуск у фоні (переживає закриття Termux):
   ```bash
   pkg install tmux -y
   tmux new -d -s bot 'cd ~/ebay-bot && python main.py --interval >> bot.log 2>&1'
   ```
   Подивитись: `tmux attach -t bot` (вийти без зупинки: `Ctrl+b`, потім `d`).
   Зупинити: `tmux kill-session -t bot`.
6. Автозапуск після ребута телефона: Termux:Boot (F-Droid) + скрипт
   `~/.termux/boot/bot.sh` з тим самим рядком tmux.
7. У налаштуваннях Android вимкни оптимізацію батареї для Termux
   (Settings → Apps → Termux → Battery → Unrestricted), інакше система вбʼє.

## Варіант 2. GitHub Actions (безкоштовно, без картки)

Модель: замість «крутиться постійно» — GitHub сам запускає **один прогін
кожні ~30 хв**. Стан між прогонами зберігається в кеші Actions.

Файли вже в проєкті: `.github/workflows/poll.yml` (полінг),
`.github/workflows/report.yml` (звіт вручну).

### Налаштування (одноразово, ~10 хв)

1. Створи акаунт на **github.com** (лише email, без картки).
2. New repository → назва напр. `ebay-bot` → **Public** → Create.
   (Public бо приватним репо дають лише 2000 хв Actions/міс, а полінг
   кожні 30 хв зʼїдає ~3600 хв/міс. Код секретів не містить — ключі
   лежать у зашифрованих Actions Secrets, `.env` у git не потрапляє.
   Хочеш Private — став cron `0 * * * *` (щогодини, ~1400 хв/міс).)
3. Заллий проєкт (з папки `D:\ebay-bot`, у Git Bash або cmd з git):
   ```bash
   cd /d D:\ebay-bot
   git init
   git add .
   git commit -m "init"
   git branch -M main
   git remote add origin https://github.com/ТВІЙ_ЛОГІН/ebay-bot.git
   git push -u origin main
   ```
   `.gitignore` уже виключає `.env`, `bot.log`, `price_history.json` — ключі
   й локальний стан у репо не потраплять.
4. У репозиторії: **Settings → Secrets and variables → Actions**:
   - вкладка **Secrets** → New repository secret, додай по одному:
     `EBAY_APP_ID`, `EBAY_CERT_ID`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`
     (значення — з твого `.env`).
   - вкладка **Variables** → New variable:
     `DISCOVERY_MODE` = `true` (пізніше зміниш на `false`),
     `EBAY_MARKETPLACE_ID` = `EBAY_DE`.
5. **Settings → Actions → General** → Workflow permissions: лишити «Read».
   Переконайся, що Actions увімкнені (Allow all actions).
6. Вкладка **Actions** → workflow `poll` → **Enable workflow**. Далі він
   піде сам за розкладом. Перший раз можна натиснути **Run workflow** вручну.

### Ліміт запитів

`poll` робить ~69 викликів eBay за прогін. Кожні 30 хв = 48/добу × 69 ≈
**3300/добу** проти ліміту eBay 5000/добу. З урахуванням джитера GitHub —
навіть менше. Не роби cron частішим за `*/25` (60/добу × 69 ≈ 4100).

### Звіт розвідки в хмарі

Вкладка **Actions → discovery-report → Run workflow**. Коли завершиться:
відкрий прогін → **Summary → Artifacts → discovery-report** → завантаж
`discovery_report.md`.

### Перехід у бойовий режим

У **Settings → Variables** зміни `DISCOVERY_MODE` з `true` на `false`.
Наступний прогін почне слати сповіщення в Telegram. (Звузити `CATEGORIES` —
відредагувати `config.py` локально і `git push`.)

### Зупинити

Вкладка **Actions → poll → ⋯ → Disable workflow**.

## Варіант 3. Raspberry Pi / старий ПК під Linux

Одноразові ~€50–70 (Pi 4/5 + карта + БЖ), далі €0 і повний контроль.

```bash
sudo apt update && sudo apt install python3 python3-pip git -y
git clone <твій приватний репо>  ~/ebay-bot   # або scp папку
cd ~/ebay-bot && pip3 install -r requirements.txt
nano .env                                      # ключі
# автозапуск через systemd:
sudo tee /etc/systemd/system/ebay-bot.service >/dev/null <<'UNIT'
[Unit]
Description=eBay price bot
After=network-online.target
[Service]
WorkingDirectory=/home/pi/ebay-bot
Environment=PYTHONIOENCODING=utf-8
ExecStart=/usr/bin/python3 main.py --interval
Restart=always
RestartSec=30
[Install]
WantedBy=multi-user.target
UNIT
sudo systemctl enable --now ebay-bot
journalctl -u ebay-bot -f          # лог
```

## Що спільне для всіх варіантів

- `.env` копіюється як є (ті самі ключі).
- `price_history.json` можна взяти з ноута (щоб не починати збір з нуля) або
  лишити порожнім `{"history":{},"listings":{},"alerted_item_ids":[],"discovery_seen":[],"key_map":{},"key_query":{},"key_conf":{}}`.
- **Запускай бота лише В ОДНОМУ місці.** Два паралельні процеси на одну базу
  = подвійні виклики API і гонка за `price_history.json`.
